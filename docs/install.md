# Installation

## Stable release

```bash
pip install pyeuvtools
```

## Development install

```bash
git clone https://github.com/suncast-org/pyEUVTools.git
cd pyEUVTools
python -m pip install -e .[dev]
```

## Notes

- `aiapy` is used for AIA wavelength-response functionality.
- the package currently targets Python 3.12+
